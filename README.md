# BingePlay – Streaming Analytics Project

BingePlay is a fictional Indian OTT streaming platform created for an Advanced SQL analytics project.

The project uses SQL to analyze users, subscriptions, shows, watch sessions, ratings, and user engagement. The main goal was to answer practical business questions that a data analyst might face in a streaming platform.

## Project Overview

The project contains 5 main tables:

* Users
* Subscriptions
* Shows
* Watch Sessions
* Ratings

The database contains around 3,000 users, 4,497 subscriptions, 100 shows, 100,351 watch sessions, and 5,000 ratings.

## What I Worked On

I used SQL queries to analyze different areas of the streaming platform, including:

* Monthly revenue and subscription analysis
* User signup trends
* Device-wise viewing activity
* Rating analysis
* Original vs acquired content
* Binge-watching behavior
* Language-wise watch time
* User engagement by age group
* Subscription plan performance
* City-wise user activity
* Consecutive weekly activity
* Churn and user reactivation patterns

## SQL Concepts Used

The project helped me practice:

* SELECT and WHERE
* GROUP BY and aggregate functions
* JOINs
* Subqueries
* CTEs
* Window functions
* ROW_NUMBER()
* LAG()
* CASE statements
* Date functions
* NULL handling
* Data filtering and analysis

The project also focuses on real analytics problems such as binge detection, consecutive-week engagement, and identifying possible churn signals.
